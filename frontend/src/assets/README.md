# Botanical edition assets

These are repository-authored mesh assets generated by
`python3 frontend/scripts/generate-scene.py` (Python standard library only).
The character interprets the user's supplied anime reference; the source image
is not embedded. There are no downloaded models, remote model URLs, decoder
dependencies, or runtime geometry generators. Keep both GLB files checked in;
Vite imports them with `?url` and emits hashed production assets.

- `rock-character.glb`: an anime character with dark, layered sculpted hair,
  closed smiling eyes, a camel trench coat with notched lapels and long tails,
  a dark waistcoat, neck/forearm wraps, and a blue-green brooch. The continuous
  body sculpt and all clothing and hair details share one mesh primitive.
  A five-joint skin supports the existing Pose, Flex, Celebrate, and Rotate
  interactions. The skeleton is cloned per instance while geometry and materials
  remain shared in the loader cache.
  Coat tails and lapels stay on the root joint while the sleeves follow the arm
  rig. Hair and clothing shapes, seams, colors, and normals are baked offline;
  there is no hair or cloth simulation.
- `garden-diorama.glb`: an irregular sandstone island, a winding path, cupped
  leaves, fern fronds, and curved flower petals. Plant geometry is merged into a
  single mesh. A small embedded alpha texture provides static soft occlusion.

The current assets total **58,156 triangles**, **four mesh primitives / draw
calls** in a normal color pass, and **1,713,516 bytes** (before HTTP compression).
The generator prints sizes and triangle counts when regenerating. glTF skinning
uses five joints; no morph targets, real-time shadow maps, contact-shadow passes,
post-processing, or per-plant frame callbacks are needed.

The scene uses React Three Fiber's demand frame loop and a maximum device pixel
ratio of 1.5. It renders while orbit controls change or a requested character
animation runs, then rests. Character actions finish within 2.2 seconds and
rotation within 0.9 seconds. API polling and RUM instrumentation are independent
of that frame loop.

The character is a stylized interpretation of the reference, not a scanned
likeness. Vertex colors are stored in linear color space as normalized bytes. Both models use embedded
buffers and the garden's only texture is embedded, so loading needs no additional
asset hosts. The generator output is deterministic.

Validate the resource structure, skin weights, bind pose and rendering budget with
`python3 -B -m unittest discover -s frontend/scripts -p 'test_*.py'`.
Validate the bounded motion state machine with
`node --test frontend/src/components/characterMotion.test.js`.
These checks do not replace a full application build or browser CPU profiling.
